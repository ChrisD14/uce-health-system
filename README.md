# UCE Health System

## Overview

UCE Health System is a distributed university medical appointment platform designed using modern software architecture principles.

The project implements:

* Microservices Architecture
* Event-Driven Architecture
* CQRS Pattern
* AWS Cloud Infrastructure
* Terraform Infrastructure as Code
* Docker Containerization
* GitHub Actions CI/CD
* PostgreSQL
* Apache Kafka
* Spring Boot
* React

## Project Goals

The platform aims to improve university healthcare services by providing:

* Medical appointment scheduling
* Doctor availability management
* Medical records management
* Real-time notifications
* Demand prediction using AI
* High availability and scalability
